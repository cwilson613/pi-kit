# Project browser

Press **F2** from the conversation to open the Project browser. Your unsent message remains in the composer.

- **Sessions** shows the current session and saved sessions for the workspace. Select a row and press Enter to inspect it. In a saved session's details, press **R** to request resume. Cancel any active turn first.
- **Work** shows the current Workbench plan and published workstreams. Enter opens the plan's task statuses or the workstream summary. An empty Workbench displays “No active work.”

Use Tab and Shift+Tab to change tabs, and the arrow keys to select rows or scroll details. **F5** refreshes the displayed snapshot. Refresh retains the selected item when it still exists; if it disappeared, the browser returns to the list.

Escape returns from details to the list, then to the conversation. F2 returns directly to the conversation. A permission request takes precedence; answering it restores the browser underneath. **Ctrl+C** cancels an active run while retaining the browser and your unsent draft.

This is the first project navigation surface. Work currently contains Workbench summaries; it does not yet browse the full work-source inventory or drill into execution evidence. The TUI still uses its fullscreen terminal layout.
