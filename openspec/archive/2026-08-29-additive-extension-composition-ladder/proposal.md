# Additive extension composition ladder

## Intent

Turn extension growth into an executable artifact ladder so each extracted domain
proves both kernel absence and capability restoration.

## Scope

Define a positive kernel boundary, kernel-only execution, kernel-plus-codescan
execution, typed-absence profiles, accumulated full-product composition, and
host, sidecar, and aggregate budgets. This change does not extract every retained
domain. It establishes the row that each later extraction must add.

## Success criteria

- A kernel-only artifact executes useful core work with optional domains absent.
- Adding codescan restores search through the same host contract used by the full product.
- Every profile checks compiled dependencies, runtime inventory, and functional behavior.
- Budgets cover the host, each extension, and aggregate installed composition.
